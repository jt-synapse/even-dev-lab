# Cadence Local Knowledge Base (`apps/cadence/kb/`)

Place your personal `.md` or `.txt` interview preparation files (resume, STAR stories, system design notes, company research) in this folder.

- Personal `.md` and `.txt` files in this directory are **gitignored** by default so private resume/interview notes are never committed.
- When this folder has no custom `.md`/`.txt` files, Cadence loads the sample fixture at `fixtures/cadence-kb-sample.md` so local tests and demos work out of the box.
- You can also add or edit live session notes directly from the Cadence companion UI.
